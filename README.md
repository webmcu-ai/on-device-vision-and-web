# on-device-vision-and-web
The original on-device vision classification with web sd card training support




This github supports the efficient web training page.



Do the demo on your cell phone, no need to save the data to the sd card,  set three classes, 300 ms burst, start camera, 30 images 

Webpage Demo for training and most of the other abilities:  https://webmcu-ai.github.io/on-device-vision-and-web/
